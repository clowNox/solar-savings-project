# Solar Savings & ROI Project

This repository is a unified data science project that analyzes and predicts the financial benefits of solar energy installations. It combines both exploratory savings analysis and robust business-focused ROI predictions.

## 📊 Modules

This project is divided into several Jupyter Notebooks, each serving a specific analytical purpose:

### Exploratory & Prediction Models
- **`Solar_mini.ipynb`**: Analyzes the relationship between household size, solar generation, setup costs, and government subsidies. It predicts the *Final Electricity Bill After Savings (₹)* using Random Forest, Decision Tree, Linear Regression, and XGBoost models.

### Business & Financial Models
- **`solar_analysis.ipynb`**: The core business modeling notebook. Predicts critical investment metrics like *ROI* (R² 0.79) and *Payback Period* (R² 0.71).
- **`solar_project_compact.ipynb`**: A streamlined, fast-running version of the core analysis.
- **`solar_dashboard_full.ipynb`**: A visualization-focused notebook for interactive dashboarding of the financial metrics.

## 📄 Documentation

- **`Solar_Savings_Documentation.docx`**: Contains in-depth analysis reports and methodology for the exploratory models.
- **`solar_model_summary.txt`**: A quick-reference text file tracking the performance metrics (RMSE, R², Accuracy) of the business ROI models.

## 🚀 Key Takeaways
By merging these approaches, this project can take localized data (e.g., Indian Rupee electricity bills and net-metering policies) and feed it into a High ROI Classifier (Accuracy: 89%), creating a powerful tool for predicting the financial viability of solar installations.
